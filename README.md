# Итоговый проект по статистике: «Соседушка»

> [!CAUTION]
> **🔴 ВАЖНО: УЧЕБНЫЙ ПРОЕКТ.** Используются учебные, демонстрационные или обезличенные данные. Примеры, имена и контакты не следует воспринимать как реальные персональные данные клиентов. Результаты относятся к учебной выборке, а не к действующему бизнесу.

Анализ продаж учебной сети за 2024–2025 годы: форматы магазинов, динамика выручки, лояльность, площадь и покупки в выходные.

## Что открыть

- **statistics_report.html** — полный отчёт с пояснениями, кодом, таблицами и графиками. Открывается в браузере без Python.
- **statistics_project.ipynb** — выполненный Jupyter Notebook с тем же анализом.
- **data/sosedushka.xlsx** — исходные учебные данные.
- **results/** — результаты шести проверок, размеры эффектов, проверка качества и версии библиотек.
- **figures/** — три рисунка, также встроенные в отчёт и ноутбук.

## Основные результаты

- В 2025 году выручка составила 11 457 582,40 руб. (+9,83%). Рост наблюдался во всех 20 магазинах.
- Распределения среднего чека магазина различаются между форматами. Сравнивать магазины для управленческого рейтинга нужно с учётом формата.
- Различие среднего чека с картой и без карты, а также различие доли чеков с картой по форматам не получили статистического подтверждения.
- Общая корреляция площади с выручкой — 0,829; внутри форматов положительная связь не наблюдается. Это не основание расширять помещения.
- В выходные средний чек в среднем по магазинам выше на 88,03 руб., но критерий знаков после поправки Холма незначим. Это не доказательство отсутствия эффекта.

Все шесть гипотез содержат H0, альтернативу, объяснение выбора критерия, расчёты и выводы. Основная единица статистических проверок — магазин. Чеки и товарные строки не выдаются за независимые магазины. Данные учебные; предположения и ограничения переноса результатов изложены в отчёте.

## Повторный запуск

Нужен Python 3.12 или новее. Из папки проекта:

```bash
python -m pip install -r requirements.txt
python run_project.py
```

Либо откройте `statistics_project.ipynb` в Jupyter и выполните все ячейки сверху вниз. Для чтения готового HTML установка библиотек не нужна.

`build_notebook.py` собирает исходный ноутбук из текста и кода. Для обычного повторного выполнения он не нужен; его запуск сбрасывает сохранённые результаты ячеек, после чего следует запустить `run_project.py`.
